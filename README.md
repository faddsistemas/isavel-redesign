# Isavel Veículos — Redesign

Site estático Next.js 15 para apresentação comercial ao cliente ([demo no GitHub Pages](https://faddsistemas.github.io/isavel-redesign/)).

## Comandos

- `npm run dev` — desenvolvimento local
- `npm run build` — export estático (`out/`)
- `npm run test:smoke` — Playwright (1280 e 390)

Veja `PRODUCT.md` para escopo e regras de produto.
